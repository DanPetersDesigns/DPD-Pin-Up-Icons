# DPD Pin-Up Icons

A themed collection of 1,015 transparent PNG character icons organized into 25 categories.

## Included Edition

### 512 Edition

Ready-to-use 512 x 512 transparent PNG icons. Each figure is centered on a consistent square canvas for reliable use as folder, launcher, shortcut, and desktop artwork.

## Linux Installation

Run ./install.sh from the release folder.

The collection will be installed to:

~/.local/share/icons/DPD-Pin-Up-Icons

Run ./uninstall.sh to remove the installed copy.

## Manual Use in KDE Dolphin

1. Right-click a folder.
2. Choose Properties.
3. Click the current folder icon.
4. Browse to an image in the 512 Edition.
5. Select the PNG and apply the change.
